# AGENTS.md

Репозиторий Telegram-бота для группового чата друзей. Ответы даёт LLM. Новые скрипты «просто попробовать API» сюда не добавлять: любая работа ведёт к боту.

## Что уже есть

- `src/client.ts` — один клиент LLM. Сейчас это Gemini (`GoogleGenAI`): ключ `GEMINI_API_KEY`, модель `GEMINI_MODEL` или запас `gemini-flash-latest`.
- `src/experiments/hello.ts` — разовая проверка, что ключ и модель отвечают: `npm run exp -- src/experiments/hello.ts`. Каталог не разрастается.
- Импорт из кода: `src/client`, не `../client.js`. Алиас задан в `tsconfig.json` (`paths`, `moduleResolution: bundler`).
- Node.js `>=24`. Зависимости ставятся локально, `npm install`.
- Секреты только в `.env`. В git его нет. В примеры и ответы ключ не копировать.

## Бот

Один процесс Node, long polling, без отдельного HTTP-сервиса и без базы.

```text
чат → бот → сборка запроса → LLM → реплай в чат
```

Бот отвечает, когда его упомянули или ответили на его сообщение. В запрос входит текст без `@бота`, текст и картинка реплая, фото этого сообщения. Системный промпт, `googleSearch` и `urlContext` передаются каждый раз. Модель сама решает, искать ли в сети и открывать ли ссылку. Картинку бот скачивает у Telegram и кладёт в `parts` как `inlineData`.

Сборка запроса только готовит аргументы `generateContent`. Вызов модели и отправка сообщения в чат живут отдельно. Если после снятия упоминания не осталось ни текста, ни картинки, модель не вызывается.

Файлы бота:

- `src/prompt.ts` — системный промпт.
- `src/bot/telegram.ts` — grammY, «печатает», нарезка ответа по 4096 символов.
- `src/bot/incoming.ts` — сборка запроса из апдейта.
- `src/bot/reply.ts` — один `generateContent`.
- Скрипт `npm run bot`. В `.env` — `TELEGRAM_BOT_TOKEN`.

## Границы

- Второй процесс «прокси и отдельный сервис» не заводить. Нагрузка на стороне LLM.
- Свой поисковик и свой загрузчик страниц не писать, пока хватает `googleSearch` и `urlContext`.
- Историю чата не копить, пока хватает текущего сообщения и реплая.
- `temperature`, `topP` и `topK` у текущего клиента не задавать: для `gemini-3.5-flash-lite` и более новых Flash API их игнорирует, на следующих версиях может ответить `400`. Тон ответа задаёт системный промпт.
- `503` с текстом `high demand` означает, что модель занята. В чат уходит короткое сообщение, повтор сам по себе не запускается.

## Стиль кода

- TypeScript, ESM, строго. ESLint: `eslint-config-airbnb` и `eslint-config-airbnb-typescript`.
- `console.log` остаётся только в `src/experiments/hello.ts`. В коде бота его нет.
- Перед завершением задачи гонять `npm run typecheck` и `npm run lint`.
- Прекоммит уже проверяет застейдженные файлы. Коммит не создавать, пока об этом не попросили.
